## Target procedure

1. Complete the myQNX account setup and obtain an authorized QNX Everywhere
   non-commercial development license. Review and accept its actual terms.
2. Install QNX Software Center and SDP 8.0. Source the supplied environment.
   Save the exact compiler version and installed package versions.
3. Run `make qnx`, capture the complete compiler output and binary hash.
   Correct any compiler or API incompatibilities; do not use mock QNX headers
   as evidence of a target build.
4. Boot a QNX 8.0 x86_64 image in QEMU using the vendor's supported workflow.
   Deploy the binary using the configured target connection.
5. Record `uname -a`. Run every scenario without `--realtime` for target
   functional parity; run `nominal`, `link-loss` and `nav-stale` with
   `--realtime` to exercise actual native timer pulses.
6. Retain raw target logs and hashes. Calculate lateness from target CSVs.
   Do not call the output hard-real-time performance or worst-case execution
   time based on a single run.
7. Update this status table and the report provenance based on actual evidence.
   Create the final English demo only after the target gate passes.
